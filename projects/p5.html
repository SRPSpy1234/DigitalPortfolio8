                        #include <Servo.h>

Servo theServo;

//								Variables

//Variable for pot pin
const int potPin = A1;
//Variable to store pot val
int potVal = 0;
//Store servo angle between 0-179 degrees
int angle;



void setup() {
  //Assign pin 9 to the servo input
  theServo.attach(9);
}

void loop() {
    //Pot val rewrite with valu
  potVal = analogRead(A1);
  //Converts potentiometer values to servo values and stores
  angle = map(potVal, 0, 1023, 0, 179);
  
  //Move servo to position
  theServo.write(angle);


		
  //15 millisecond delay
  delay(15);


}

Project Description

Code Generation

The code generation of this project was very simple. It only required around 3 variables and one mapping function. We used the servo library to control the servo's angle. We took the value of the potentiometer and mapped it to the servo's values of 0-179 degrees. The code was super easy to write and we filled out our variables and stuff.

Building

The build portion of this project was one of my favorites. Rather than buuilding, I designed and 3D prited the meter itself, the shell the circuitry and the motor arm. I designed the shell to be a 6" rounded box with a mounting bracket for the servo and a hole for the potentiometer. I made the arm around 2.5" long and designed it to be an arrow pointing to the set mood. The build was really fun and I quite enjoyed it.

Errors and Real Life Application

Fortunaley, I didn't face any errors in this project. Everything went super smothly and I was able to do everything first try. The 3D printing has no issues and the code works perfectly. The only thing that took some extra time is that when designing the arm, the mounting portion was a few millimeters to small and I had to go back and size it up. For real life application, this project could be used in an office to control a dial that shows someones availablilty.
