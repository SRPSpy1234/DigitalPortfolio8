  pinMode(12, INPUT);
  //Function that will set servo pin as OUTPUT

  //Function that will set conrol pin as OUTPUT
  pinMode(9, OUTPUT);

  //Function that will set enabled pin for as OUTPUT

}

Project Description

Code Generation

The code for this project was a bit of a challange. First off, we were not allowed to use any outside resources, so I used previous projects and their code to get a foundation for this projects code. I also had a bit of trial and error when getting the motor and servo to work correctly together. The motor was a bit of a challange as it had trouble reading the potentiometer values and kept tweaking back and forth. I had to add a better mapping function to get the motor to read the potentiometer values correctly. The servo was easier to get working, but I had to do a bunch of trial and error. For the LEDs and the button things went pretty smoothly. Overall, the code took some effort but in the end it was okay.

Building

For the build portion of this project, I 3D printed my physical project. I designed the 3D model in onshape and then printed it out at home. My project was a lighthouse that has a rotating light so I had to make space for buttons, potentiometers, and the servo. I also needed a spot for the motor to mount so i had to fit it in ot the project. There was less trial and error in the building process but it still took some time to get the design right. I had to make sure that everything fit together and print multiple parts to get it working. I also had to do some minor adjustments after printing with a dremel tool to get everything to fit together. Overall, the building process was pretty smooth and I am happy with how it turned out.

Errors and Real Life Application

The errors I had with this project were mostly with the code. The motor was a bit challenging to get working correctly and it took some trial and error to get it working. The servo was easier to get working but it still required some new adjustments. The LEDs and button were pretty easy to get working. Overall, the code was the most difficult part of this project. In terms of real life application, this project could be used as a lighthouse or a rotating light for a display.
